# Pottu Multiplayer v4

Four browser windows can join the same room. Run `npm install`, then `npm start`, and open `http://localhost:3000`.

Key update: P3's cards become visible to all players after the first card is led, then remain visible until all 13 Pottus finish. Each player sees their own seat at the bottom, with the next clockwise player on the right, their teammate opposite, and the remaining player on the left.
